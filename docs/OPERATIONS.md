# Operación v1

Iniciar con `jedertech.sh` en Linux o `jedertech.cmd` en Windows, desde cualquier directorio. Los lanzadores verifican Node 22.13+, dependencias, build y Chromium local, y piden confirmación para instalar faltantes. Para sesión visible: elegir nueva extracción en modo visible o `./meta-scraper session --url URL --limit N --db BASE --visible [--profile main|temp]`. En la terminal: `Ctrl+C`/`p` pausa, `r` continúa el objetivo pendiente del mismo trabajo, `+N` crea otro tramo sin borrar pendientes, `e` exporta, `h` muestra salud sin tráfico y `q` cierra. Alcanzar el objetivo o exportar no cierra Chromium. Si falta progreso tras scroll o «Ver más», espera como máximo un minuto, avisa a los 30 segundos y retoma en cuanto detecta nuevos IDs o el control. La espera se cancela con `Ctrl+C`/`p`. Tras cinco errores GraphQL consecutivos sin IDs nuevos, la pausa permite recargar manualmente; solo `r`/`+N` reanuda. Un 403/429 detiene nuevas solicitudes automáticas y conserva la pestaña para inspección manual. Luego, `r` inicia un intento explícito reabriendo el perfil.

`--mode advertisers` también funciona en sesión visible y cuenta anunciantes nuevos con ID de página de JSON estructurado. Los anuncios de tarjeta sin ese ID se guardan, pero no suman al objetivo de anunciantes. Ejecutá la sesión directamente en la terminal; una tubería que recibe `Ctrl+C` puede terminar también y cerrar la ventana. En páginas muy grandes, vigilá la memoria del equipo.

Si se cierra la pestaña principal, la sesión conserva el trabajo y ofrece `r` para reabrir perfil y búsqueda. Si termina el proceso, los lotes ya confirmados siguen en SQLite. Consultar `./meta-scraper jobs list`, luego `./meta-scraper resume --job ID --visible` si se desea iniciar un navegador nuevo. El cursor exacto no se recupera. Exportar cualquier trabajo/base sin red con `./meta-scraper export --job ID --format csv` o `./meta-scraper export --db BASE --format csv`. `./meta-scraper profile open main` abre en blanco para navegación y autenticación manual; `profile reset main` pide confirmación y no toca SQLite.

La base se crea en `data/meta-scraper.sqlite`. Para respaldarla con la aplicación, usar `Storage.backup(ruta)` (`VACUUM INTO`), verificar `PRAGMA integrity_check` y comparar conteos; no copiar archivos WAL/SHM de una base activa. `data/` y `diagnostics/` no se versionan. Los logs normales muestran progreso compacto; `--verbose` agrega detalles técnicos saneados. Nunca incluir cookies, tokens ni cuerpos completos de GraphQL en logs.

Pruebas offline: `npm test`; Chromium y proceso real con páginas locales: `npm run test:browser-local`; simulación local de 5.000: `npm run benchmark:local`. El audit online de npm requiere conexión al registro; si no está disponible, `npm audit --offline` solo consulta la caché local y no descarta vulnerabilidades recientes.

Para entregar una copia sin datos, usar la opción **7. Formatear proyecto** o `./meta-scraper format` y escribir `FORMATEAR`. Borra bases, respaldos, exportaciones y diagnósticos locales; conserva código, documentación, dependencias y Git. Cerrar sesiones antes de formatear. El formateo no hace solicitudes de red.
